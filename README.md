# Simple Interest Calculator



## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest per year
- T = Time in years

## Example

- Principal = 10000
- Rate = 5%
- Time = 2 years

Calculation:

SI = (10000 × 5 × 2) / 100

**Simple Interest = 1000**
